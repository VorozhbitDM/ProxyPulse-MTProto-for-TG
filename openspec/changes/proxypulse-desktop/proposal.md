## Why

Пользователи в регионах с блокировкой Telegram не могут быстро получить актуальные MTProto-прокси из канала [@ProxyMTProto](https://t.me/ProxyMTProto): сайт `t.me` часто недоступен, а ручной перебор ссылок из постов медленный и неудобен. Нужно настольное приложение под Windows, которое автоматически загружает свежие прокси, проверяет доступность и позволяет подключиться в Telegram в один клик.

## What Changes

- Новое Windows-приложение **ProxyPulse** (версия **1.0**), .NET Framework 4.7.2, упаковка в один `.exe`.
- Стартовый экран с описанием и кнопкой «Начать поиск».
- Загрузка списка MTProto-прокси из канала @ProxyMTProto с обходом блокировки `t.me` (альтернативные источники и настраиваемый транспортный прокси).
- Параллельная проверка доступности (TCP/connect + замер задержки), прогресс-бар и кнопка «Прервать поиск».
- Живой список рабочих прокси во время сканирования; сортировка по пингу по возрастанию.
- Строка прокси: адрес, пинг, кнопка «Проверить»; hover-подсветка; клик открывает `tg://proxy?...` в Telegram.
- Взаимодействие со списком (перепроверка отдельной строки, клик) без остановки глобального скана.
- Минималистичный, быстрый UI; семантическое версионирование (1.0, 1.1, …) в сборке и «О программе».

## Capabilities

### New Capabilities

- `proxy-feed-ingest`: получение и парсинг списка MTProto-прокси из @ProxyMTProto и резервных источников при недоступности `t.me`.
- `proxy-health-scan`: параллельная проверка прокси, отмена, перепроверка одной записи, сортировка по задержке.
- `desktop-ui`: окна, прогресс, список, deep link в Telegram, версия приложения.

## Impact

- Новый solution/project в репозитории (`src/ProxyPulse/` или аналог): WinForms (или WPF) на .NET Framework 4.7.2.
- Сетевой слой: `HttpClient`/`WebClient`, опциональный SOCKS5/HTTP-прокси для запросов к заблокированным хостам.
- Сборка: MSBuild + publish single-file exe (ILMerge/Costura или аналог для 4.7.2).
- Внешние зависимости: только NuGet для HTTP/SOCKS при необходимости; без встраивания полноценного VPN в v1.
- Пользователь должен иметь установленный Telegram Desktop для `tg://` ссылок.
